# 😊 Perspective Simulator

## 📌 Overview
A Python-based simulation program that analyzes user input situations and provides positive, structured reframing to improve perspective and emotional thinking.

---

## 🧠 Features
- Situation classification system
- Rule-based reframing engine
- Mood tracking system
- File-based history storage
- Multi-file modular Python architecture

---

## 💻 Technologies Used
- Python
- Object-Oriented Programming (OOP)
- File Handling (.txt storage)
- Dictionaries & loops
- Modular programming

---
